# Complete movement and contact family (September 18)

Private experiment, **OFF** by default. `SARECOMP_NATIVE_MOVEMENT_CONTACT=1`
selects the connected family; the global native-CPU OFF override and diagnostic
mode still retain the original path. This does not enable the retired isolated
movement or NEAR experiments. The delivered September 18 patch is unchanged.

## Initial 37-owner scope

The two original movement/query roots `8C073018` and `8C074214` now enter one
37-owner native operation: movement/contact resolution, NEAR polygon search
and eligibility, TOUCH candidates, triangle contacts, classification and their
matrix/vector children. The authoring inventory covers 8,573 instructions,
648 delay slots and 327 call sites. Authoring reads authenticated PAL bytes;
the game does not decode those instructions.

One live RAM capability and per-owner source proofs cover the connected
operation. Internal children call each other directly. Real foreign calls
flush accounting, release that borrowed execution state and revoke every
proof before any continuation. Candidates, linked lists, counts and callback
targets remain live guest data. Every admitted write still excludes code and
literal ranges, including when the installed immutable range set is narrower.

The exact original lexical FPU scopes are checked against hashed retained AOT
sources. The family preserves the selector's `0902`/`0903` tail calls, contact
ordering, matrix effects and the original simulation clock. Unsupported
accesses resume the exact original instruction, including pre-branch PR for
delay-slot failures. Private original continuations retain the sparse public
dispatch table; completion also preserves the original exit source.

## Qualification

Windows and Linux each pass 164 complete CPU/register/RAM comparisons over
four guest FPU/bank modes. Fixtures cover moving characters, real NEAR/TOUCH
data, reversed triangles, full contact arrays, classification, selector tails
and callback mutations. An additional twelve cases per platform execute the
actual retained AOT continuations, including misalignment, partial memory
faults, observer replacement and FPU-mode changes. The deliberate SZ change
inside an existing original stack frame retains its original invalid-return
frontier; it is not reported as a successful gameplay return.

Actual hidden Windows Gamma Emerald Coast also completes with the group

Component success alone does not demonstrate a performance benefit.

## Complete 61-owner closure

The second revision incorporates eleven inverse-angle owners, twelve complete
matrix/vector SDK owners and the record-copy operation into the same admitted
movement/contact operation. The inventory now covers 10,908 instruction PCs
and 761 delay slots. These are connected children of the movement and contact
roots, not independent global feature toggles. Real gameplay/event callbacks
still revoke the shared proofs and memory capability.

The record copier replaces its full guest jump table and per-word permissions
with one bounded admission. It preserves the short path's descending copy,
the long path's ascending copy and extra final read, overlapping source and
destination behavior, saved stack words and every final register. Stack/data
aliases, unaligned data, code writes and incomplete mappings retain the whole
original operation before any native side effect. Private read-only SDK blocks
also receive local continuation routing after their original exit provenance;
the global dispatch table is unchanged.

Both Windows and Linux pass 276 complete CPU/RAM cases in four FPU/bank modes
and twenty actual-AOT cases. The additional coverage includes overlapping
copies, the extra-read boundary, code-write interruption, singular/invertible
matrices, vector intersections and angle quadrants. Original faults remain
original faults. Evidence:

- `runs/contact-closure-components-win-a-20260918.log`
- `runs/contact-closure-aot-win-b-20260918.log`
- `runs/contact-closure-components-linux-launch-20260918.log`

The matched Windows Gamma pair retains all sixteen endpoint fields and 48
updates. It executes 67,515 internal calls and 843 foreign calls, with no
unsupported-access resumes. The initial revision crossed 9,218 foreign calls
in its corresponding 48-update window. Against the same new executable with
the entire contact group OFF, execution cycles fall 6.69%, quantized execution
CPU is unchanged at 18.75 ms/boundary, and process CPU rises 10.00%. This is
not a demonstrated whole-frame improvement. See
`runs/contact-closure-gamma-comparison-windows-20260918.json`.

The matched Linux Gamma pair also retains all sixteen endpoint fields and 68
updates. Execution CPU/update falls 7.03%, process CPU changes -0.03% (neutral),
and new-image throughput falls 2.96%. The window contains 85,707 internal calls,
1,203 foreign calls and no unsupported-access resumes. These results do not
demonstrate a whole-frame gain. See
`runs/contact-closure-gamma-comparison-linux-20260918.json`.
The requested short Knuckles pairs are complete, with all sixteen endpoint
fields and 68 updates matched in each scene. Sky Deck reduces execution
CPU/update 4.08%, changes process CPU +0.66% and new images/s -2.89%.
Lost World reduces execution CPU/update 15.96%, process CPU/update 11.17%,
and increases new images/s 18.03%. The active windows have zero resumes.
See `runs/contact-closure-sky-comparison-linux-20260918.json` and
`runs/contact-closure-lost-comparison-linux-20260918.json`.

This is a consistent reduction in measured Linux execution CPU, but a useful
whole-frame improvement is currently demonstrated only in Lost World. Keep
the group private-OFF while the next complete model-submission composition
is qualified; the delivered patch is unchanged. Do not repeat these unchanged
three scene pairs or convert the VM result into a Deck FPS claim.
