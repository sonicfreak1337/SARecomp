# Sonic Adventure Recompiled 0.50.0 — Beta 1

Welcome to the first release of **Sonic Adventure Recompiled**, an unofficial
PC port of the original Dreamcast adventure.

**The game is fully playable, with all seven stories playable from start to
finish.** This is a **work-in-progress beta**: further polish, compatibility
improvements and performance work are planned.

**You must provide your own copy of Sonic Adventure.** Only the supported
**Dreamcast PAL v1.003 (1999)** GDI and all three accompanying tracks are accepted.
Original disc images and installed gameplay content are not included.
See the [installation guide and track hashes](https://github.com/sonicfreak1337/SARecomp/blob/main/docs/INSTALLATION.md).

Setup is English-only. The game's supported text and voice languages can be
changed in Options. A short `INSTALLATION.txt`, `SHA256SUMS.txt` and a release
manifest accompany the installers.

## Features

- Play natively on **Windows, Linux and Steam Deck**.
- Choose the original **4:3** presentation, **widescreen** or **ultrawide**.
- Use the original camera or optional **modern camera controls**.
- Adjust graphics, sound, languages and controls in an in-game Options menu
  inspired by the original, including **Sound Test**.
- Keep your progress organized with **save profiles and automatic backups**.
- Choose **Original** or **Recompiled** game timing.

## Linux compatibility

The Linux installer is intended for **Linux Mint (including Cinnamon), Ubuntu
and other compatible 64-bit distributions**. It requires x86-64, glibc 2.31+,
X11 or XWayland, and a Vulkan 1.3-capable GPU and driver. No particular desktop
environment is required. Linux and Deck installation checks passed in our
Linux VM; Mint has not yet been tested separately.

## Steam Deck

Install in **Desktop Mode**, then add the installed game to Steam and play in
Gaming Mode. **No sudo password or Proton is required.** Leave forced Steam
Play compatibility disabled.

**Always launch the game through Steam Gaming Mode. Starting it in Desktop
Mode can freeze the Steam Deck.** Use Desktop Mode for installation only.

New Deck installations use **1280 × 800**, **16:10**, **fullscreen**, **Vulkan**,
**Game timing → Original** and **VSync → Off**. These timing and VSync settings
are recommended for the best current Deck performance.

## Known issues

- **Steam Deck Desktop Mode:** launching the game there can freeze the device.
  **Always start the game through Steam Gaming Mode.** Install in Desktop Mode.
- **Steam Deck performance:** demanding stages, bosses and cutscenes can still
  slow down. Further performance improvements are planned. A stable 60 FPS
  across the whole game is not yet established.
- **Widescreen cutscenes:** some scenes can look glitchy outside the original
  4:3 area. This is confirmed in **Tails' first cutscene**. Select Original 4:3
  as a workaround.
- **Stability:** bugs and isolated crashes may still occur. Please report
  reproducible problems so they can be investigated.

## Saves and bug reports

Reinstalling preserves existing saves and settings. Close the game before
running setup. Backups and save-profile management are available in
**Options → Profiles**.

Report the version, platform, character, scene and steps to reproduce. For
performance reports, include **in-game SIM FPS**, timing mode and VSync setting.
Diagnostic reports are optional. Do not upload original game files or personal saves.
