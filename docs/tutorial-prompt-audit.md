## Result and semantic correction

The safe native seam is **`sonic_native_draw_pretransformed_textured` ->
`draw_pretransformed_stream(context, true)`**, SDK entry **8C63EC48**, with
**PR 8C9014CE, r4 8C798718, r5 4**. The source is an interleaved 24-byte
vertex strip. It is neither Sprite2D nor the separate 8C63EB08 split-stream
dispatch. No AOT regeneration or new guest hook is required for this seam.

The filename `bar_ab` is misleading: both original decoded bars visibly
advertise **A: Next / X: Back**. The tutorial update accepts **A for Next,
and either B or X for Back**. Therefore a dynamically resolved Action::A/B
bar is correct for the accepted B alternative; a faithful complete replacement
can show Action::A for Next and Action::X / Action::B for Back, deduplicating
equal physical labels. Host Confirm/Cancel bindings are not the contract.

Proof: update owner 8C900F32, state 1, reads pressed word 8C754D9C.
8C900F9C tests mask 0x4; 8C900FA2 passes +1 to 8C901A90. If A is absent,
8C900FD4..8C900FDC constructs/tests mask 0x402; 8C900FE2 passes -1 to
the same helper. The adapter's `sonic_peripheral_button_a/b/x` constants
are 0x4 / 0x2 / 0x400 and `sonic_peripheral_buttons` preserves that map.
A wins if both directions are pressed. Preserve these original semantics.

## Closed call chain

SUMMARY initializer 8C900B60 chooses `tuto_cmn` for language 0 and
`tuto_cmn_e` otherwise, acquired through 8C099690 at TEXLIST 8C9097D4.
Display owner 8C9012E8 binds that list through 8C608C0C at 8C9013D8.
8C901438/143A selects ordinal 0. At 8C9014CA it calls 8C07DFEE, with
r4=0, fr4/fr5=(288,400) for language 0 or (265,410) otherwise, and fr6=100.

8C07DFEE extracts ordinal and flags, gets the bound TEXLIST from 8C6733C0,
follows ordinal * 12 to TEXNAME+8, then loads its descriptor. Width/height
are descriptor+36/+40. For r4=0, the anchor is the upper left and the
generated rectangle uses the full texture dimensions. Helper 8C07EAFA
sets UVs (0,0), (0,1), (1,0), (1,1) in shared 24-byte vertices at 8C798718.
8C07E31E..8C07E35C publishes position x/y and q=1/fr6. The resulting four
records contain float x/y/q/u/v and packed ARGB at offsets 0/4/8/12/16/20.

At 8C07E372, r6 receives descriptor word 0, the actual registered texture
key. 8C07E374 sets r4=8C798718; 8C07E376 sets r5=4. r7 carries the selected
alpha mode. 8C07E378..8C07E388 restores the caller's stack/registers and
PR, then **tail-jumps to 8C63EC48** using literal 8C07E3B4. Therefore the
native leaf retains SUMMARY PR 8C9014CE, with no stack walk or speculative
intermediate-call tracking required.

`src/sonic-adventure-pal-v1003-native-graphics-boundaries.hpp` binds EC48,
length C4, as `sa_nj_draw_pretransformed_textured`. The adapter exports
`sonic_native_draw_pretransformed_textured`, which calls
`draw_pretransformed_stream(context,true)`.

## Concrete replacement contract

Apply replacement only after the existing registered texture resolution has
succeeded and the original immediate state transaction/vertices are valid.
Keep a helper local to this draw family, with the following conjunction:

1. Textured leaf, PR 8C9014CE, source 8C798718, count 4, expected UV/finite
   rectangle shape. These are additional witnesses, not asset identity.
2. `context.loaded_aot->active_module_for_address(PR)` matches SUMMARY SHA
   below, source_start 0x82D61000, runtime backing 0x0C900000, byte_size
   695821, and a nonzero live lifecycle_generation. Any retained match/cache
   is generation-bound and invalidated when this module retires.
3. Current TEXLIST is 8C9097D4 (accept its same-backing alias), exactly
   three entries. Use `read_texlist` and existing live catalog ownership
   helpers, not the address alone. Exact archive is TUTO_CMN.PRS or
   TUTO_CMN_E.PRS, matching the encoded identity above; ordinal is 0 and
   its `texture_archive_entry_pvrt_identity` matches the appropriate SHA.
4. Follow that list's ordinal-0 descriptor and require descriptor word 0
   equals the resolved input r6 key. Also prove that the original resolver's
   selected **first matching SDK row** is this live descriptor/publication,
   with valid guest token/generation. The resolver intentionally permits
   duplicate keys, so key equality alone is insufficient. Its current
   diagnostics carry opaque identities, not complete catalog provenance;
   use/extend its internal owner witness or compare the first matching row
   and the existing exact TEXLIST/PVM publication authority. Never choose
   a replacement by GBIX alone, filename alone, or another matching key.

(and host vertices if a measured layout needs expansion). Reuse the
original source colors, depth, sampler, triangle strip, UI presentation

TEXLIST, descriptor, registered key, original archive or its materialized
texture. `prepare_native_immediate_state` and
`finish_native_immediate_state` must still run exactly once with the
**original** selection and original count. Suppressing the original call
with an early Return would skip its SDK state/cursor effects.

as existing menu/texture surface code does. Cache by archive/language,
resolved glyph style, the actual bindings used, and graphics-resource
lifetime; destroy or retire through the existing native graphics lifetime
owner, never the original archive's release path. On match/raster/resource
failure retain the original bar.
