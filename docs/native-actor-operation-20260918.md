## State transfer and fallback semantics

The twelve reviewed BRAF/BRA sites transfer between actual retained owners.
They preserve the caller's original stack and incoming continuation instead
of inventing a call/return pair. A computed target is captured before its
delay slot. Unrecognized targets resume before the original branch; a
fallback after a completed transfer starts at the target and never repeats
the completed delay slot. The native execution loop follows these transfers
without recursively building artificial host call frames.

The author validates exact source hashes, original branch targets, source
dependencies and lexical FPU epochs. Owners sharing an original epilogue
receive distinct C++ label namespaces. Private original continuations
include the retained read-only state blocks. The global original dispatch
table remains unchanged. The existing original path stays available.
