# Menu artwork

`options-background.png` is the unmodified 2560×1920 SA background supplied
by the project owner on 2026-09-12 for the new in-game Options menu.
SHA-256: `87b1a09d2a384825c0a82d05b857136fec64ac282f56cfc441d8ae57bc5d9330`.

The renderer preserves its aspect at 4:3, 16:9 and ultrawide sizes. Text,
buttons and focus indicators remain native-resolution vector/GDI elements.
Original `SONICAD/OPTION.ADX` remains installed game content, not UI artwork.
