# Contributing

Thank you for helping improve Sonic Adventure Recompiled.

For a bug report, use the [issue form](https://github.com/sonicfreak1337/SARecomp/issues/new/choose)
and include the exact build, platform, character, stage and reproduction steps.
Screenshots or a short video help with graphics and timing problems. Distinguish
SIM FPS from presentation FPS and identify Original or Recompiled timing.
Do not upload original game files or personal saves. Diagnostics are optional.

For code changes, read [development setup](docs/DEVELOPMENT.md) and
[AGENTS.md](AGENTS.md). Preserve the original game behavior and save compatibility;
new enhancements should have a clear boundary from the original path. Keep a
change focused, explain its observable effect and include relevant verification.
Do not change or repackage the frozen baseline as a side effect of development.

Feature suggestions should describe the player benefit and fit the original
game's presentation. Check existing issues before opening a new one.
